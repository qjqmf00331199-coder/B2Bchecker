# B2B 재고/거래 관리 프로그램

거래처별 입출고 거래를 등록하고, 품번/거래처 기준으로 조회하며, 엑셀로 가져오기·내보내기까지 지원하는 데스크톱 재고 관리 프로그램입니다. PySide6(Qt) 기반 GUI + SQLite DB로 동작합니다.

## 주요 기능

- **거래 등록**: 분류/날짜/거래처/품번/구분(입고·출고)/수량/단가 입력, 금액 자동 계산
- **거래처별 단가 자동 적용**: 거래처+품번 선택 시 `price_list`에 등록된 단가가 있으면 우선 적용, 없으면 품목의 기본단가 사용
- **품번 조회**: 특정 품번의 전체 거래 내역, 기간 필터, 총 입고량/총 출고량/현재 재고 요약
- **거래처별 조회**: 특정 거래처의 전체 거래 내역, 기간 필터
- **마스터 데이터 관리**: 거래처/품목/거래처별 단가를 추가·수정, 엑셀로 일괄 등록
- **엑셀 연동**: 조회 화면 결과를 `.xlsx`로 내보내기, 거래/거래처/품목을 엑셀에서 가져오기

## 다운로드

소스 전체를 받을 필요 없이 exe 파일 하나만 받아도 실행됩니다.

1. [Releases 페이지](https://github.com/qjqmf00331199-coder/B2Bchecker/releases/latest) 접속
2. Assets에서 **B2B_Inventory.exe** 클릭해 다운로드
3. 원하는 폴더에 놓고 실행 (첫 실행 시 같은 폴더에 `inventory.db` 자동 생성)

- `main` 브랜치에 새 커밋이 올라갈 때마다 **Latest (main)** 릴리스가 최신 빌드로 자동 갱신됩니다.
- 특정 버전을 고정해서 쓰고 싶으면 태그가 붙은 릴리스(`v1.0.0` 등)에서 받으면 됩니다.
- 커밋별 빌드 결과물이 필요하면 [Actions 탭](https://github.com/qjqmf00331199-coder/B2Bchecker/actions) → 해당 워크플로 실행 → Artifacts에서도 받을 수 있습니다(로그인 필요, 90일 후 만료).

## 실행 방법

### 빌드된 실행 파일 사용 (Windows)

다운로드한 `B2B_Inventory.exe`(또는 로컬 빌드 시 `dist/B2B_Inventory.exe`)를 더블클릭하면 바로 실행됩니다. DB 파일(`inventory.db`)은 exe와 같은 폴더에 자동 생성됩니다.

### 소스에서 직접 실행

```bash
pip install -r requirements.txt
python -m app.main
```

Python 3.10+ 권장. 실행 시 프로젝트 루트에 `inventory.db`가 없으면 자동 생성됩니다.

## 화면 구성

메인 창은 위(거래 등록 폼) / 아래 좌우(품번 조회, 거래처별 조회) 3분할 구조이며, 상단 툴바의 **마스터 데이터 관리** 버튼으로 거래처/품목/단가를 등록합니다.

### 1. 거래 등록 (상단)

1. 분류 입력 (예: 가공비, 재료비 — 선택 항목, 비워도 됨)
2. 날짜 선택 (기본값: 오늘)
3. 거래처명 입력 → 자동완성 목록에서 선택
4. 품번 또는 품명 입력 → 자동완성 목록에서 선택 (거래처+품번 선택되면 단가가 자동으로 채워짐)
5. 구분(입고/출고), 수량, 단가 확인 후 **저장**
6. **엑셀로 가져오기**로 여러 건을 한 번에 등록 가능, **엑셀로 내보내기**로 전체 거래내역 저장 가능(분류/거래처명/날짜/구분/품번/수량 순)

> 거래처·품번은 자동완성 목록에서 선택하거나, 목록에 있는 거래처명/품번 텍스트를 정확히 입력해도 인식됩니다.
>
> 거래 등록 폼 아래에는 전체 거래내역 테이블이 표시되며, 저장·가져오기 후 자동 갱신됩니다.

### 2. 품번 조회 (하단 좌측)

- 품번/품명 입력 후 **조회**
- **전체 기간** 체크 해제 시 날짜 범위 필터 적용
- 결과 아래에 총 입고량 / 총 출고량 / 현재 재고(기초재고 + 입고 − 출고) 표시
- **엑셀로 내보내기**로 조회 결과 저장

### 3. 거래처별 조회 (하단 우측)

- 거래처명 입력 후 **조회**, 날짜 필터·엑셀 내보내기는 품번 조회와 동일

### 4. 마스터 데이터 관리 (툴바 버튼)

탭 3개로 구성:

- **거래처**: 거래처명(중복 불가) + 담당자/연락처 등록·수정
- **품목**: 품번(PK, 수정 시 변경 불가) + 품명 + 기본단가 + 기초재고 등록·수정
- **거래처별 단가**: 거래처를 선택하고 품목별 단가를 개별 지정(설정 시 기본단가보다 우선 적용)

## 엑셀 가져오기 양식

가져오기는 **첫 번째 시트, 2행부터**(1행은 헤더로 간주하고 건너뜀) 읽습니다. 열 순서는 아래와 같고, `?`가 붙은 열은 생략 가능합니다.

| 대상 | 열 순서 |
|---|---|
| 거래처 | 거래처명, 담당자/연락처? |
| 품목 | 품번, 품명, 기본단가?, 기초재고? |
| 거래 내역 | 분류, 거래처명, 날짜, 구분(입고/출고), 품번, 수량 |

- 단가는 거래처별 단가 → 품목 기본단가 순으로 자동 적용됩니다.
- **거래처/품번이 마스터에 없으면 자동으로 새로 등록됩니다.** (품목은 품명이 비어 있으므로 나중에 마스터 데이터 관리에서 품명/기본단가를 채워 넣으면 됩니다.)
- 분류/거래처명/날짜/품번이 공란이면 **"미기재"**로, 수량이 공란이면 **0**으로 채워서 가져옵니다. 구분(입고/출고)만은 필수값이라 비어 있으면 해당 행이 실패 처리됩니다.
- **같은 날짜·거래처·품번·구분·수량·분류 조합이 이미 있으면 중복으로 보고 건너뜁니다.** 같은 파일을 여러 번 가져와도 데이터가 겹쳐 쌓이지 않습니다.
- 가져오기 완료 후 추가/중복/실패 건수를 안내합니다.

## 데이터 저장 위치

SQLite 파일 하나(`inventory.db`)로 저장되며, 실행 파일 기준 같은 폴더에 위치합니다. 백업이 필요하면 이 파일만 복사하면 됩니다.

## exe 빌드

Windows 실행 파일은 GitHub Actions(`.github/workflows/build-exe.yml`)로 빌드합니다. 로컬에서 직접 빌드하려면:

```bash
pip install pyinstaller
pyinstaller build.spec
```

## 변경 이력

### v0.3.0

- 거래 등록 폼에 **분류** 입력 필드 추가 (가공비/재료비 등 자유 텍스트, 선택 항목)
- 거래 내역 엑셀 가져오기 열 순서 변경: **분류 / 거래처명 / 날짜 / 구분 / 품번 / 수량**
- 거래 등록 폼에 전체 거래내역 테이블 + **엑셀로 내보내기** 버튼 추가
- 가져오기 시 거래처/품번이 마스터에 없으면 자동 등록
- 분류/거래처명/날짜/품번 공란은 "미기재", 수량 공란은 0으로 채워서 가져오기 (더 이상 실패 처리하지 않음)
- 같은 거래(날짜·거래처·품번·구분·수량·분류)를 다시 가져와도 중복 저장되지 않도록 방지
- 품번 자동완성에서 "품번 - 품명" 전체가 아니라 품번만 입력해도 조회되도록 수정
